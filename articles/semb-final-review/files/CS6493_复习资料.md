## 2. Core Concepts / 核心概念梳理

### Lecture 1: Introduction to NLP

#### NLP — Natural Language Processing（自然语言处理）
- **Definition（定义）**: A branch of AI that aims to make computers learn, process, and manipulate natural languages. / 人工智能的一个分支，旨在让计算机学习、处理和操纵自然语言。
- **Key Points（要点）**:
  - Intersects linguistics, computer science, and AI. / 交叉语言学、计算机科学和AI。
  - Goal: bridge the gap between human communication and computer understanding. / 目标：弥合人类交流与计算机理解之间的鸿沟。

#### History of NLP（NLP发展历程）
- **Definition（定义）**: The evolution of NLP methods from rule-based systems to neural approaches. / NLP方法从基于规则到神经方法的演进。
- **Key Points（要点）**:
  - Rule-based (1950s-1980s): hand-crafted rules, limited coverage. / 基于规则：手工规则，覆盖有限。
  - Statistical (1990s-2010s): probabilistic models, feature engineering. / 统计方法：概率模型，特征工程。
  - Neural (2010s-present): end-to-end learning, representation learning. / 神经方法：端到端学习，表示学习。

#### Challenges in NLP（NLP面临的挑战）
- **Definition（定义）**: Fundamental difficulties in processing natural language. / 处理自然语言的根本困难。
- **Key Points（要点）**:
  - Ambiguity: words/sentences have multiple meanings. / 歧义性：词/句有多种含义。
  - Context dependence: meaning varies with context. / 上下文依赖：含义随上下文变化。
  - World knowledge: understanding requires background knowledge. / 世界知识：理解需要背景知识。

### Lecture 2: Language Model

#### Language Model（语言模型）
- **Definition（定义）**: A probability distribution over sequences of words, assigning probabilities to sentences. / 词序列上的概率分布，为句子分配概率。
- **Key Points（要点）**:
  - Chain rule: $P(w_1, ..., w_n) = \prod_{i=1}^{n} P(w_i | w_1, ..., w_{i-1})$
  - Core task: predict the next word given context. / 核心任务：给定上下文预测下一个词。

#### N-gram Model（N-gram模型）
- **Definition（定义）**: A language model using Markov assumption to approximate the conditional probability by only considering the previous n-1 words. / 使用马尔可夫假设，仅考虑前n-1个词来近似条件概率的语言模型。
- **Key Points（要点）**:
  - Bigram: $P(w_t|w_1...w_{t-1}) \approx P(w_t|w_{t-1})$
  - Trigram: $P(w_t|w_1...w_{t-1}) \approx P(w_t|w_{t-2}, w_{t-1})$
  - Trade-off: larger n captures more context but requires more data (sparsity). / 权衡：更大的n捕获更多上下文但需要更多数据（稀疏性）。

#### Smoothing（平滑技术）
- **Definition（定义）**: Techniques to handle zero-probability n-grams by redistributing probability mass to unseen events. / 通过将概率质量重新分配给未观测事件来处理零概率n-gram的技术。
- **Key Points（要点）**:
  - **Laplace (Add-1)**: $P_{Laplace}(w|c) = \frac{C(c,w)+1}{C(c)+V}$ / 加1平滑
  - **Add-k**: generalize add-1 with parameter k. / 用参数k推广加1。
  - **Interpolation**: combine different n-gram orders: $P = \lambda_1 P_{bi} + \lambda_2 P_{uni}$ / 混合不同n-gram阶
  - **Backoff**: use shorter n-gram when longer one has zero count. / 当长n-gram计数为零时使用短n-gram。
  - **Kneser-Ney**: best smoothing method, uses continuation count and discount. / 最佳平滑方法，使用延续计数和折扣。

#### Perplexity（困惑度）
- **Definition（定义）**: A metric to evaluate language models, measuring how well the model predicts a sample. / 评估语言模型的指标，衡量模型预测样本的能力。
- **Key Points（要点）**:
  - $\text{PPL} = 2^{-\frac{1}{N}\sum_{i=1}^{N}\log_2 P(w_i|\text{context})}$
  - Lower PPL = better model. / 困惑度越低，模型越好。
  - Intuition: the effective branching factor at each word. / 直觉：每个词的有效分支因子。

#### Neural Language Models（神经语言模型）
- **Definition（定义）**: Language models based on neural networks that learn continuous word representations. / 基于神经网络的语言模型，学习连续词表示。
- **Key Points（要点）**:
  - Feedforward: fixed window context, learn embedding + hidden layer. / 前馈：固定窗口上下文。
  - RNN-based: variable-length context, hidden state carries history. / RNN：变长上下文，隐状态携带历史。
  - Advantages over n-gram: no sparsity, share parameters, handle longer context. / 优于n-gram：无稀疏性、参数共享、处理更长上下文。

### Lecture 3: Word Embedding

#### One-hot Encoding（独热编码）
- **Definition（定义）**: Representing each word as a sparse vector with a single 1 at the word's index. / 将每个词表示为仅在词索引处为1的稀疏向量。
- **Key Points（要点）**:
  - No similarity information: all vectors are orthogonal. / 无相似度信息：所有向量正交。
  - High dimensional, sparse. / 高维、稀疏。

#### Distributional Semantics（分布式语义）
- **Definition（定义）**: The idea that words appearing in similar contexts have similar meanings. / 出现在相似上下文中的词具有相似含义的思想。
- **Key Points（要点）**:
  - "You shall know a word by the company it keeps" (Firth). / 根据词的伙伴来认识词。
  - Foundation of all embedding methods. / 所有嵌入方法的基础。

#### Word2Vec — Skip-gram（跳字模型）
- **Definition（定义）**: Predict context words given a center word. / 给定中心词预测上下文词。
- **Key Points（要点）**:
  - Objective: maximize $\sum_{t=1}^{T} \sum_{-c \le j \le c, j \ne 0} \log P(w_{t+j}|w_t)$
  - $P(o|c) = \frac{\exp(u_o^T v_c)}{\sum_{w=1}^{V} \exp(u_w^T v_c)}$ (softmax)
  - Problem: softmax over full vocabulary is expensive. / 问题：全词汇表softmax代价大。

#### Word2Vec — CBOW（连续词袋模型）
- **Definition（定义）**: Predict center word given context words. / 给定上下文词预测中心词。
- **Key Points（要点）**:
  - Faster training than Skip-gram, but slightly worse for rare words. / 比Skip-gram训练快，但对罕见词稍差。

#### Negative Sampling（负采样）
- **Definition（定义）**: Approximate softmax by sampling a small number of negative examples. / 通过采样少量负例来近似softmax。
- **Key Points（要点）**:
  - Objective: $\log \sigma(u_o^T v_c) + \sum_{k=1}^{K} \mathbb{E}[\log \sigma(-u_k^T v_c)]$
  - K = 5-20 typically. / K通常为5-20。
  - Significantly reduces computation. / 显著减少计算量。

#### GloVe — Global Vectors（全局向量）
- **Definition（定义）**: A method that factorizes the log co-occurrence matrix to learn word vectors. / 分解对数共现矩阵来学习词向量的方法。
- **Key Points（要点）**:
  - Objective: $J = \sum_{i,j=1}^{V} f(X_{ij})(w_i^T \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij})^2$
  - Combines global co-occurrence statistics with local context window methods. / 结合全局共现统计和局部上下文窗口方法。
  - $f(X_{ij})$ is a weighting function to down-weight very frequent co-occurrences. / 加权函数，降低高频共现的权重。

#### ELMo — Embeddings from Language Models（基于语言模型的嵌入）
- **Definition（定义）**: Contextual word embeddings derived from bidirectional LSTM language models. / 从双向LSTM语言模型中提取的上下文词嵌入。
- **Key Points（要点）**:
  - Different from static embeddings (Word2Vec, GloVe): each word gets different embedding depending on context. / 与静态嵌入不同：每个词根据上下文获得不同嵌入。
  - $\text{ELMo}_k = \gamma^{task} \sum_{j=0}^{L} s_j^{task} h_{k,j}^{LM}$ (weighted sum of all LSTM layers)
  - Breakthrough: contextual representations. / 突破：上下文表示。

### Lecture 4: Transformer and Pretraining-Finetuning

#### Scaled Dot-Product Attention（缩放点积注意力）
- **Definition（定义）**: Attention mechanism computing compatibility using dot product of Query and Key, scaled by $\sqrt{d_k}$. / 使用Query和Key的点积计算兼容性，并除以$\sqrt{d_k}$缩放的注意力机制。
- **Key Points（要点）**:
  - $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
  - Scaling prevents softmax from entering regions with tiny gradients. / 缩放防止softmax进入梯度极小的区域。

#### Multi-Head Attention（多头注意力）
- **Definition（定义）**: Running multiple attention functions in parallel with different projected Q, K, V, then concatenating results. / 使用不同的投影Q、K、V并行运行多个注意力函数，然后拼接结果。
- **Key Points（要点）**:
  - $\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$
  - Each head: $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$
  - Allows model to attend to different representation subspaces. / 允许模型关注不同的表示子空间。

#### Transformer Architecture（Transformer架构）
- **Definition（定义）**: An encoder-decoder architecture based entirely on attention, without recurrence. / 完全基于注意力、无循环的编码器-解码器架构。
- **Key Points（要点）**:
  - **Positional Encoding**: injects position info since attention is permutation-invariant. / 位置编码：注入位置信息，因为注意力是排列不变的。
    - $PE_{(pos,2i)} = \sin(pos/10000^{2i/d_{model}})$, $PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d_{model}})$
  - **Layer Normalization**: stabilizes training. / 层归一化：稳定训练。
  - **Residual Connection**: helps gradient flow. / 残差连接：帮助梯度流动。
  - Encoder: self-attention + FFN per layer. / 编码器：每层自注意力+前馈网络。
  - Decoder: masked self-attention + cross-attention + FFN per layer. / 解码器：每层掩码自注意力+交叉注意力+前馈网络。

#### BERT — Bidirectional Encoder Representations from Transformers（双向编码器表示）
- **Definition（定义）**: A pretrained model using bidirectional Transformer encoder with masked language modeling and next sentence prediction. / 使用双向Transformer编码器，通过掩码语言模型和下一句预测进行预训练的模型。
- **Key Points（要点）**:
  - **Masked LM (MLM)**: randomly mask 15% tokens, predict masked tokens. / 随机掩码15%的token，预测被掩码的token。
  - **Next Sentence Prediction (NSP)**: predict if sentence B follows sentence A. / 预测句子B是否紧跟句子A。
  - Bidirectional context → better for NLU tasks. / 双向上下文→更适合NLU任务。

#### GPT — Generative Pre-trained Transformer（生成式预训练Transformer）
- **Definition（定义）**: A pretrained model using Transformer decoder with autoregressive language modeling. / 使用Transformer解码器通过自回归语言模型进行预训练的模型。
- **Key Points（要点）**:
  - Left-to-right autoregressive: $P(w_t|w_1...w_{t-1})$
  - Better for generation tasks. / 更适合生成任务。

#### Pretrain-Finetune Paradigm（预训练-微调范式）
- **Definition（定义）**: First pretrain on large unlabeled data, then finetune on task-specific labeled data. / 先在大规模无标注数据上预训练，再在任务特定的标注数据上微调。
- **Key Points（要点）**:
  - Pretraining: learn general language representations. / 预训练：学习通用语言表示。
  - Finetuning: adapt to downstream tasks with small labeled data. / 微调：用少量标注数据适配下游任务。

### Lecture 5: NLU Tasks

#### Text Classification（文本分类）
- **Definition（定义）**: Assigning predefined categories to text. / 为文本分配预定义类别。
- **Key Points（要点）**:
  - Applications: sentiment analysis, topic classification, spam detection. / 应用：情感分析、主题分类、垃圾邮件检测。
  - Approach: encode text → classifier (linear layer on [CLS] token). / 方法：编码文本→分类器。

#### NER — Named Entity Recognition（命名实体识别）
- **Definition（定义）**: Identifying and classifying named entities (person, organization, location, etc.) in text. / 识别和分类文本中的命名实体。
- **Key Points（要点）**:
  - Formulated as sequence labeling with BIO tags (B-Begin, I-Inside, O-Outside). / 用BIO标签的序列标注。
  - Example: "B-PER I-PER O B-LOC" for "John Smith lives in London". / 示例："John Smith lives in London"的BIO标注。

#### Relation Extraction（关系抽取）
- **Definition（定义）**: Identifying the semantic relationship between two entities in text. / 识别文本中两个实体之间的语义关系。
- **Key Points（要点）**:
  - Input: sentence with marked entities; Output: relation type. / 输入：标记实体的句子；输出：关系类型。
  - Pipeline: NER → Relation Classification. / 流水线：命名实体识别→关系分类。

#### Question Answering（问答）
- **Definition（定义）**: Automatically answering questions based on given context. / 基于给定上下文自动回答问题。
- **Key Points（要点）**:
  - **SQuAD**: extractive QA, answer is a span from context. / 抽取式问答，答案是上下文中的片段。
  - **BiDAF**: Bidirectional Attention Flow, computes attention from context-to-query and query-to-context. / 双向注意力流，计算上下文到查询和查询到上下文的注意力。

#### NLI — Natural Language Inference（自然语言推理）
- **Definition（定义）**: Determining the logical relationship between a premise and a hypothesis. / 判断前提和假设之间的逻辑关系。
- **Key Points（要点）**:
  - Three classes: Entailment (蕴含), Contradiction (矛盾), Neutral (中立).
  - Also called Recognizing Textual Entailment (RTE). / 也称为文本蕴含识别。

### Lecture 6: NLG Tasks

#### Machine Translation（机器翻译）
- **Definition（定义）**: Automatically translating text from one language to another. / 自动将文本从一种语言翻译成另一种语言。
- **Key Points（要点）**:
  - SMT → NMT transition. / 从统计机器翻译到神经机器翻译的过渡。
  - Seq2Seq with attention: encoder processes source, decoder generates target with attention over source. / 带注意力的序列到序列模型。
  - BLEU score: primary evaluation metric. / 主要评估指标BLEU。

#### Dialogue Systems（对话系统）
- **Definition（定义）**: Systems that can converse with humans. / 能与人类对话的系统。
- **Key Points（要点）**:
  - **Task-oriented**: pipeline NLU → DST (Dialog State Tracking) → POL (Policy) → NLG. / 任务型：流水线架构。
  - **Chitchat**: end-to-end generation, no specific task goal. / 闲聊型：端到端生成，无特定任务目标。

#### NLG Evaluation Metrics（NLG评估指标）
- **Definition（定义）**: Metrics for assessing the quality of generated text. / 评估生成文本质量的指标。
- **Key Points（要点）**:
  - **BLEU**: n-gram precision with brevity penalty; mainly for MT. / n-gram精确率+短句惩罚；主要用于机器翻译。
  - **ROUGE**: n-gram recall; mainly for summarization. / n-gram召回率；主要用于摘要。
  - **METEOR**: considers synonyms and stemming; better correlation with human judgment. / 考虑同义词和词干；与人类判断相关性更好。
  - **BERTScore**: uses BERT embeddings for semantic similarity. / 使用BERT嵌入计算语义相似度。

#### Beam Search（束搜索）
- **Definition（定义）**: A decoding strategy that keeps top-k (beam width) partial sequences at each step. / 每步保留top-k（束宽）部分序列的解码策略。
- **Key Points（要点）**:
  - Balances between greedy search (k=1) and exhaustive search. / 在贪心搜索和穷举搜索之间平衡。
  - Larger beam width → better but slower. / 更大的束宽→更好但更慢。

### Lecture 7: Large Language Models

#### Scaling Laws（缩放定律）
- **Definition（定义）**: Empirical findings that LLM performance improves predictably with increases in model size, data size, and compute. / 经验发现：LLM性能随模型规模、数据规模和计算量增加而可预测地提升。
- **Key Points（要点）**:
  - Performance depends primarily on scale (N: params, D: data, C: compute). / 性能主要取决于规模。
  - Chinchilla scaling: optimal model requires ~20 tokens per parameter. / Chinchilla缩放：最优模型每个参数需要约20个token。

#### In-Context Learning（上下文学习）
- **Definition（定义）**: The ability of LLMs to learn from examples provided in the prompt without parameter updates. / LLM从提示词中提供的示例学习的能力，无需更新参数。
- **Key Points（要点）**:
  - **Zero-shot**: no examples, just instruction. / 零样本：无示例，仅指令。
  - **Few-shot**: a few examples in the prompt. / 少样本：提示词中包含少量示例。
  - Emerges with scale; smaller models cannot do it well. / 随规模涌现；小模型效果不好。

#### Chain-of-Thought (CoT) Prompting（思维链提示）
- **Definition（定义）**: Adding step-by-step reasoning demonstrations in the prompt to elicit reasoning from LLMs. / 在提示词中添加逐步推理演示，引导LLM进行推理。
- **Key Points（要点）**:
  - "Let's think step by step" can trigger CoT even without demonstrations. / "让我们逐步思考"即使没有演示也能触发CoT。
  - Especially helpful for math and logic tasks. / 对数学和逻辑任务特别有帮助。

#### Emergent Abilities（涌现能力）
- **Definition（定义）**: Abilities that are not present in smaller models but appear in larger models. / 小模型不具备但在大模型中出现的能力。
- **Key Points（要点）**:
  - Examples: in-context learning, CoT reasoning, complex instruction following. / 示例：上下文学习、CoT推理、复杂指令遵循。
  - Qualitative leap at certain scale thresholds. / 在特定规模阈值处的质变。

#### Instruction Tuning（指令微调）
- **Definition（定义）**: Finetuning LLMs on instruction-formatted datasets to improve instruction-following ability. / 在指令格式的数据集上微调LLM以提高指令遵循能力。
- **Key Points（要点）**:
  - Converts pretrained LMs into helpful assistants. / 将预训练语言模型转化为有用的助手。
  - Key step between base model and chat model. / 基础模型和对话模型之间的关键步骤。

### Lecture 8: Prompts and Alignment

#### Prompt Engineering（提示工程）
- **Definition（定义）**: Designing and optimizing prompts to elicit desired outputs from LLMs. / 设计和优化提示词以引导LLM产生期望输出。
- **Key Points（要点）**:
  - **Hard prompts**: discrete text prompts, human-readable. / 离散文本提示，人类可读。
  - **Soft prompts**: continuous vectors learned via backpropagation (P-tuning, Prefix Tuning). / 通过反向传播学习的连续向量（P-tuning、Prefix Tuning）。

#### Prompt Tuning vs Instruction Tuning（提示微调 vs 指令微调）
- **Definition（定义）**: Prompt tuning updates only soft prompt vectors; instruction tuning updates all or most model parameters on instruction data. / 提示微调仅更新软提示向量；指令微调在指令数据上更新所有或大部分模型参数。
- **Key Points（要点）**:
  - Prompt tuning: fewer parameters, task-specific. / 参数更少，特定任务。
  - Instruction tuning: better generalization across tasks. / 跨任务泛化更好。

#### RLHF — Reinforcement Learning from Human Feedback（基于人类反馈的强化学习）
- **Definition（定义）**: A method to align LLMs with human preferences using reinforcement learning. / 使用强化学习使LLM与人类偏好对齐的方法。
- **Key Points（要点）**:
  - **Step 1 — SFT**: Supervised finetuning on high-quality demonstrations. / 监督微调：在高质量演示数据上微调。
  - **Step 2 — Reward Model**: Train a model to predict human preference scores from comparisons. / 训练奖励模型：从比较数据中预测人类偏好分数。
  - **Step 3 — PPO**: Optimize LLM policy using reward model as reward signal, with KL penalty to prevent deviation from SFT model. / 使用奖励模型作为奖励信号优化LLM策略，加KL惩罚防止偏离SFT模型。

#### Alignment Tax（对齐税）
- **Definition（定义）**: The performance degradation on certain capabilities (e.g., reasoning, coding) that may occur after alignment training. / 对齐训练后某些能力（如推理、编程）可能出现的性能下降。
- **Key Points（要点）**:
  - Trade-off between helpfulness and safety. / 有用性和安全性之间的权衡。

#### Constitutional AI（宪法AI）
- **Definition（定义）**: An alignment method where the AI follows a set of principles (constitution) to self-critique and revise outputs. / AI遵循一组原则（宪法）来自我批评和修订输出的对齐方法。
- **Key Points（要点）**:
  - Reduces need for human feedback labels. / 减少对人类反馈标签的需求。

#### DPO — Direct Preference Optimization（直接偏好优化）
- **Definition（定义）**: An alternative to RLHF that directly optimizes the policy from preference data without training a separate reward model. / RLHF的替代方案，直接从偏好数据优化策略，无需训练单独的奖励模型。
- **Key Points（要点）**:
  - Simpler pipeline: no reward model, no RL training. / 更简单的流程：无需奖励模型和RL训练。
  - Uses a closed-form solution to the constrained reward maximization problem. / 使用约束奖励最大化问题的闭式解。

### Lecture 10: Efficient Training of LLMs

#### Model Weights（模型权重）
- **Definition（定义）**: The parameters of the model that are learned during training, adjusted by the optimizer based on gradients to minimize the loss function. / 模型在训练过程中学习到的参数，由优化器根据梯度调整以最小化损失函数。
- **Key Points（要点）**:
  - Model weights take 2 bytes (fp16) or 4 bytes (fp32) per parameter. / 每个参数权重占用2字节（fp16）或4字节（fp32）。
  - A 1.5B parameter GPT-2 model requires 3GB for weights in fp16. / 15亿参数的GPT-2模型在fp16下权重需3GB。

#### Mixed Precision Training（混合精度训练）
- **Definition（定义）**: A training technique where model weights are stored as fp16, forward and backward propagation use fp16, but an fp32 copy of parameters and optimizer states are kept for computing updates. / 模型权重以fp16存储，前向和反向传播使用fp16，但保留fp32参数副本和优化器状态用于计算更新。
- **Key Points（要点）**:
  - Enables use of high-throughput tensor core units of GPUs. / 使得GPU的高吞吐量张量核心单元得以利用。
  - An fp32 copy is kept for accurate parameter updates. / 保留fp32副本以精确更新参数。

#### Optimizer States（优化器状态）
- **Definition（定义）**: The internal data stored by the optimizer during training, used to update model weights efficiently. / 优化器在训练过程中存储的内部数据，用于高效更新模型权重。
- **Key Points（要点）**:
  - Adam optimizer: momentum ($4\Psi$) + variance ($4\Psi$) + fp32 copy ($4\Psi$) → total $12\Psi$ bytes.

#### Activation Memory（激活值内存）
- **Definition（定义）**: Intermediate results stored from the forward pass for the backward pass. / 前向传播中存储的中间结果，用于执行反向传播。
- **Key Points（要点）**:
  - Proportional to: transformer_layers × hidden_dim × seq_len × batch_size.
  - 1.5B GPT-2 with seq_len=1K, batch=32 requires ~60GB. / 15亿GPT-2约需60GB。

#### Naïve Model Parallelism（朴素模型并行）
- **Definition（定义）**: Vertical partition that spreads groups of model layers across multiple GPUs. / 垂直分割，将模型层组分配到多个GPU上。
- **Key Points（要点）**:
  - Advantage: fits very large models onto limited hardware. / 优点：可将超大模型放入有限硬件。
  - Disadvantage: GPU idle (bubbles) due to sequential execution. / 缺点：顺序执行导致GPU空闲（气泡）。

#### Pipeline Parallelism — GPipe（流水线并行）
- **Definition（定义）**: Splits a batch into smaller micro-batches and pipelines execution over GPUs. / 将批次拆分为微批次并流水线化到不同GPU上。
- **Key Points（要点）**:
  - Advantage: less bubble, better GPU utilization. / 优点：减少气泡，更好利用GPU。
  - Disadvantage: need to find optimal micro-batch size. / 缺点：需要找最优微批次大小。

#### Tensor Parallelism — Megatron-LM（张量并行）
- **Definition（定义）**: Each GPU processes a slice of a tensor and aggregates only when needed, using column/row parallelism. / 每个GPU只处理张量的一个切片，仅在需要时聚合，使用列/行并行。
- **Key Points（要点）**:
  - Column Parallelism: split weight by columns; f=identity (fwd), all-reduce (bwd); g=all-reduce (fwd), identity (bwd). / 列并行：按列拆分权重。
  - Row Parallelism: split weight by rows; complementary pattern. / 行并行：按行拆分；互补模式。
  - TP for Self-Attention: each head on different GPU. / 自注意力TP：每个头在不同GPU上。
  - Up to 76% scaling efficiency with 512 GPUs. / 512个GPU可达76%扩展效率。

#### Data Parallelism — DP vs DDP（数据并行）
- **Definition（定义）**: Dataset is split into shards, each allocated to a device holding a full model replica. / 数据集被拆分为分片，每个分片分配给持有完整模型副本的设备。
- **Key Points（要点）**:
  - **DP**: single-process, multi-thread; GPU0 overloaded → OOM risk. / 单进程多线程；GPU0过载→OOM风险。
  - **DDP**: multi-process; each GPU independently consumes mini-batch; gradients averaged during backward → balanced. / 多进程；负载均衡。

#### DeepSpeed ZeRO（零冗余优化器）
- **Definition（定义）**: Instead of replicating full params/gradients/optimizer states on each GPU, ZeRO stores only a slice and synchronizes on-demand. / 不复制完整状态，仅存储切片并按需同步。
- **Key Points（要点）**:
  - **Stage 1 ($P_{os}$)**: Optimizer State Partitioning → 4× reduction, same comm volume. / 优化器状态分区→4倍减少。
  - **Stage 2 ($P_{os+g}$)**: Add Gradient Partitioning → 8× reduction, same comm volume. / 增加梯度分区→8倍减少。
  - **Stage 3 ($P_{os+g+p}$)**: Add Parameter Partitioning → $N_d$× reduction, 50% more comm. / 增加参数分区→$N_d$倍减少，通信+50%。

#### Adapter（适配器微调）
- **Definition（定义）**: Adds extra trainable parameters after attention and FC layers of a frozen pretrained model. / 在冻结预训练模型的注意力层和全连接层后添加可训练参数。
- **Key Points（要点）**:
  - Bottleneck structure: project d→m→d ($m \ll d$). Parameters per layer: $2md + d + m$.
  - Includes skip-connection. / 包含残差连接。
  - Disadvantage: increases inference latency (up to 30% for GPT-2 medium). / 缺点：增加推理延迟。

#### LoRA — Low-Rank Adaptation（低秩适配）
- **Definition（定义）**: Adds low-rank decomposition matrices (A and B) in parallel to pretrained weight $W_0$, where $\Delta W = BA$. / 将低秩分解矩阵并行添加到预训练权重上。
- **Key Points（要点）**:
  - $W_0$ frozen; only A ($r \times d$) and B ($d \times r$) trained. / 仅训练A和B。
  - No additional inference latency (parallel, not sequential). / 无额外推理延迟。
  - After training: $W = W_0 + BA$ (merge for zero overhead). / 训练后可合并。
  - Comparable performance with orders of magnitude fewer parameters. / 用少几个数量级参数实现相当性能。

### Lecture 11: RAG

#### RAG — Retrieval-Augmented Generation（检索增强生成）
- **Definition（定义）**: A paradigm that enhances LLMs by integrating external knowledge bases, combining retrieval and generation. / 通过整合外部知识库来增强LLM的范式，结合检索和生成。
- **Key Points（要点）**:
  - Tackles up-to-date and long-tail knowledge. / 解决最新知识和长尾知识问题。
  - Reduces hallucination by grounding generated content. / 通过为生成内容提供依据来减少幻觉。
  - Reduces training/inference costs. / 降低训练/推理成本。

#### Vector Database（向量数据库）
- **Definition（定义）**: A database storing information as vectors, supporting metadata, filtering, scalability, etc. / 以向量形式存储信息的数据库，支持元数据、过滤、可扩展性等。
- **Key Points（要点）**:
  - Full data management solution, not just a search library. / 完整数据管理方案，不仅是搜索库。

#### Embedding in RAG（RAG中的嵌入）
- **Definition（定义）**: Converting text chunks into vector embeddings using models like BERT or GPT. / 使用BERT或GPT等模型将文本块转换为向量嵌入。
- **Key Points（要点）**:
  - Process: Load → Split → Embed → Store. / 流程：加载→拆分→嵌入→存储。
  - Smaller text pieces work better. / 较小的文本片段效果更好。

#### Indexing Methods（索引方法）

##### LSH — Locality-Sensitive Hashing（局部敏感哈希）
- **Definition（定义）**: Hashing algorithm for approximate nearest neighbor search, mapping similar vectors to same buckets. / 用于近似最近邻搜索的哈希算法，将相似向量映射到同一桶。
- **Key Points（要点）**: Fast but approximate; good for high-speed ANN. / 快速但近似。

##### PQ — Product Quantization（乘积量化）
- **Definition（定义）**: Breaks vectors into sub-vectors, encodes with codebook. / 将向量拆分为子向量，用码本编码。
- **Key Points（要点）**: Saves memory at cost of some precision. / 节省内存但牺牲部分精度。

##### HNSW — Hierarchical Navigable Small World（分层可导航小世界）
- **Definition（定义）**: Graph algorithm with hierarchical structure for efficient similarity search. / 具有层次结构的图算法，用于高效相似度搜索。
- **Key Points（要点）**: High recall and query speed but higher memory. / 高召回和查询速度，但内存较高。

#### Naïve RAG vs Advanced RAG（朴素RAG vs 高级RAG）
- **Definition（定义）**: Naïve RAG uses simple retrieve-then-generate; Advanced RAG improves pre-retrieval, retrieval, and post-retrieval. / 朴素RAG用简单检索-生成；高级RAG改进各阶段。
- **Key Points（要点）**:
  - Naïve RAG issues: poor retrieval quality, irrelevant context, hallucination. / 问题：检索质量差、不相关上下文、幻觉。
  - Advanced RAG: optimized chunking, better indexing, re-ranking, query rewriting. / 改进：优化分块、更好索引、重排序、查询重写。

#### What to Retrieve?（检索什么?）
- **Definition（定义）**: Determining the type and scope of information to retrieve. / 确定检索信息的类型和范围。
- **Key Points（要点）**:
  - Chunk-level vs document-level retrieval. / 块级 vs 文档级检索。
  - Different granularity affects precision and quality. / 不同粒度影响精度和质量。

#### When to Retrieve?（何时检索?）
- **Definition（定义）**: Determining the optimal timing for retrieval during generation. / 确定生成过程中检索的最佳时机。
- **Key Points（要点）**:
  - **One-time**: retrieve before generation. / 一次性：生成前检索。
  - **Token-based (Toolformer)**: special tokens trigger retrieval. / 基于Token：特殊Token触发检索。
  - **Uncertainty-based (FLARE)**: retrieve when confidence is low. / 基于不确定性：置信度低时检索。
  - **Iterative/Adaptive**: multiple rounds interleaved with generation. / 迭代：检索与生成交替多轮。

#### How to Use Retrieved Information?（如何使用检索到的信息?）
- **Definition（定义）**: How to incorporate retrieved documents into generation. / 如何将检索文档整合到生成中。
- **Key Points（要点）**:
  - In-context (concatenate to prompt). / 上下文内拼接。
  - Attention-based fusion (RETRO, FiD). / 基于注意力的融合。
  - Post-processing (re-ranking, filtering). / 后处理（重排序、过滤）。

## 3. Key Formulas & Theorems / 重点公式与定理

### Chain Rule for Language Models（语言模型的链式法则）
- **Formula（公式）**: $P(w_1, ..., w_n) = \prod_{i=1}^{n} P(w_i | w_1, ..., w_{i-1})$
- **Variables（变量说明）**: $w_i$ = i-th word in sequence / 序列中第i个词
- **Conditions（适用条件）**: Exact decomposition of joint probability / 联合概率的精确分解

### N-gram Approximation（N-gram近似）
- **Formula（公式）**: $P(w_t | w_1...w_{t-1}) \approx P(w_t | w_{t-n+1}...w_{t-1})$
- **Variables（变量说明）**: n = order of n-gram model / n-gram模型的阶数
- **Conditions（适用条件）**: Markov assumption of order n-1 / n-1阶马尔可夫假设

### Laplace Smoothing（拉普拉斯平滑）
- **Formula（公式）**: $P_{Laplace}(w|c) = \frac{C(c,w) + 1}{C(c) + V}$
- **Variables（变量说明）**: C(c,w) = count of w following context c / 上下文c后w的计数; V = vocabulary size / 词汇表大小
- **Conditions（适用条件）**: Add-1 smoothing; often over-smooths / 加1平滑；常常过度平滑

### Perplexity（困惑度）
- **Formula（公式）**: $\text{PPL} = 2^{-\frac{1}{N}\sum_{i=1}^{N}\log_2 P(w_i|\text{context})}$
- **Variables（变量说明）**: N = total number of words / 总词数
- **Conditions（适用条件）**: Evaluation of language models; lower is better / 语言模型评估；越低越好

### Scaled Dot-Product Attention（缩放点积注意力）
- **Formula（公式）**: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
- **Variables（变量说明）**: Q = queries, K = keys, V = values, $d_k$ = key dimension / 查询、键、值、键维度
- **Conditions（适用条件）**: Core of Transformer attention mechanism / Transformer注意力机制的核心

### Multi-Head Attention（多头注意力）
- **Formula（公式）**: $\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$, where $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$
- **Variables（变量说明）**: h = number of heads / 头数; $W^O$ = output projection / 输出投影
- **Conditions（适用条件）**: Transformer multi-head attention / Transformer多头注意力

### Positional Encoding（位置编码）
- **Formula（公式）**: $PE_{(pos,2i)} = \sin(pos/10000^{2i/d_{model}})$, $PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d_{model}})$
- **Variables（变量说明）**: pos = position / 位置; i = dimension index / 维度索引; $d_{model}$ = model dimension / 模型维度
- **Conditions（适用条件）**: Sinusoidal positional encoding in original Transformer / 原始Transformer的正弦位置编码

### Negative Sampling（负采样）
- **Formula（公式）**: $\log \sigma(u_o^T v_c) + \sum_{k=1}^{K} \mathbb{E}[\log \sigma(-u_k^T v_c)]$
- **Variables（变量说明）**: $v_c$ = center word vector / 中心词向量; $u_o$ = context word vector / 上下文词向量; $\sigma$ = sigmoid; K = number of negative samples / 负样本数
- **Conditions（适用条件）**: Word2Vec training with negative sampling / 使用负采样的Word2Vec训练

### GloVe Objective（GloVe目标函数）
- **Formula（公式）**: $J = \sum_{i,j=1}^{V} f(X_{ij})(w_i^T \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij})^2$
- **Variables（变量说明）**: $X_{ij}$ = co-occurrence count / 共现计数; $f$ = weighting function / 加权函数
- **Conditions（适用条件）**: GloVe word embedding training / GloVe词嵌入训练

### Memory Consumption Formula（内存消耗公式）
- **Formula（公式）**:
  - Model weights (fp16): $2\Psi$ bytes
  - Gradients (fp16): $2\Psi$ bytes
  - Optimizer states (Adam, fp32): $12\Psi$ bytes
  - **Total: $16\Psi$ bytes**
- **Variables（变量说明）**: $\Psi$ = number of model parameters / 模型参数数量
- **Conditions（适用条件）**: Mixed precision training with Adam optimizer / 使用Adam优化器的混合精度训练

### Adapter Parameter Count（适配器参数数量）
- **Formula（公式）**: Parameters per layer $= 2md + d + m$
- **Variables（变量说明）**: d = original feature dimension / 原始特征维度; m = bottleneck dimension ($m \ll d$) / 瓶颈维度
- **Conditions（适用条件）**: Bottleneck adapter architecture / 瓶颈适配器架构

### LoRA Weight Update（LoRA权重更新公式）
- **Formula（公式）**: $W = W_0 + \Delta W = W_0 + BA$, where A is $r \times d$, B is $d \times r$
- **Variables（变量说明）**: $W_0$ = frozen pretrained weight ($d \times d$) / 冻结的预训练权重; $r$ = rank ($r \ll d$) / 低秩分解的秩
- **Conditions（适用条件）**: LoRA fine-tuning; BA can merge into $W_0$ for zero inference overhead / LoRA微调；可合并实现零推理开销

### DeepSpeed ZeRO Memory Reduction（DeepSpeed ZeRO内存减少）
- **Formula（公式）**:
  - Stage 1 ($P_{os}$): 4× memory reduction
  - Stage 2 ($P_{os+g}$): 8× memory reduction
  - Stage 3 ($P_{os+g+p}$): $N_d$× memory reduction
- **Variables（变量说明）**: $N_d$ = DP degree (number of GPUs) / 数据并行度（GPU数量）
- **Conditions（适用条件）**:
  - Stage 1 & 2: same communication volume as DP / 通信量与DP相同
  - Stage 3: 50% increase in communication volume / 通信量增加50%

## 4. Typical Questions & Solutions / 典型例题与解答

### Question 1: N-gram Probability Calculation / N-gram概率计算
**Problem（问题）**: Given the corpus "I love NLP I love deep learning", calculate the bigram probability P(love|I) using Laplace smoothing with vocabulary size V=6. / 给定语料"I love NLP I love deep learning"，用拉普拉斯平滑计算二元概率P(love|I)，词汇表大小V=6。

**Solution（解答）**:
- Count C(I) = 2, C(I, love) = 2
- $P_{Laplace}(\text{love}|\text{I}) = \frac{C(\text{I, love}) + 1}{C(\text{I}) + V} = \frac{2+1}{2+6} = \frac{3}{8} = 0.375$
- Without smoothing: $P(\text{love}|\text{I}) = 2/2 = 1.0$ (over-confident)
- 拉普拉斯平滑将概率从1.0降至0.375，避免过度自信。

### Question 2: Perplexity Calculation / 困惑度计算
**Problem（问题）**: A language model assigns probabilities $P(w_1)=0.2$, $P(w_2|w_1)=0.5$, $P(w_3|w_1,w_2)=0.4$ to a 3-word sequence. Calculate the perplexity. / 语言模型对3词序列分配概率0.2, 0.5, 0.4，计算困惑度。

**Solution（解答）**:
- $P(\text{sequence}) = 0.2 \times 0.5 \times 0.4 = 0.04$
- $\text{PPL} = 2^{-\frac{1}{3}(\log_2 0.2 + \log_2 0.5 + \log_2 0.4)}$
- $= 2^{-\frac{1}{3}(-2.322 - 1 - 1.322)} = 2^{\frac{4.644}{3}} = 2^{1.548} \approx 2.93$
- 困惑度约2.93，表示每个位置平均约2.93个等概率选择。

### Question 3: Attention Mechanism Computation / 注意力机制计算
**Problem（问题）**: Given Q, K, V each of dimension $d_k=4$, explain how scaled dot-product attention is computed and why scaling is needed. / 给定Q、K、V维度$d_k=4$，解释缩放点积注意力的计算以及为什么需要缩放。

**Solution（解答）**:
- Step 1: Compute scores = $QK^T$ (dot product of query with all keys)
- Step 2: Scale by $\sqrt{d_k} = \sqrt{4} = 2$ → scores/2
- Step 3: Apply softmax → attention weights
- Step 4: Multiply by V → output
- **Why scaling?** When $d_k$ is large, dot products grow large, pushing softmax into regions with tiny gradients (near 0 or 1). Dividing by $\sqrt{d_k}$ keeps the variance of scores stable. / 当$d_k$大时，点积值变大，使softmax进入梯度极小的区域。除以$\sqrt{d_k}$保持方差稳定。

### Question 4: BERT vs GPT / BERT与GPT对比
**Problem（问题）**: Compare BERT and GPT in terms of architecture, pretraining objectives, and suitable tasks. / 比较BERT和GPT在架构、预训练目标和适用任务上的异同。

**Solution（解答）**:

| Aspect / 方面 | BERT | GPT |
|---|---|---|
| Architecture / 架构 | Encoder-only / 仅编码器 | Decoder-only / 仅解码器 |
| Attention / 注意力 | Bidirectional / 双向 | Unidirectional (masked) / 单向（掩码） |
| Pretraining / 预训练 | MLM + NSP | Autoregressive LM / 自回归LM |
| Best for / 最适合 | NLU tasks (classification, NER, QA) / 理解任务 | NLG tasks (generation) / 生成任务 |
| Context / 上下文 | Full bidirectional / 完全双向 | Left-to-right only / 仅从左到右 |

### Question 5: Memory Budget Calculation / 内存预算计算
**Problem（问题）**: Consider a 7B parameter LLM. Calculate the total GPU memory required for training with mixed precision (Adam optimizer), including model weights, gradients, and optimizer states. / 考虑一个70亿参数的LLM，计算混合精度训练所需总GPU内存。

**Solution（解答）**:
- $\Psi = 7B = 7 \times 10^9$
- Total = $16\Psi = 16 \times 7 \times 10^9$ bytes ≈ 112 GB
- Breakdown: Weights ($2\Psi$) = 14GB, Gradients ($2\Psi$) = 14GB, Optimizer states ($12\Psi$) = 84GB
- Additional activation memory also needed. / 还需额外的激活值内存。
- 结论：约112GB，远超单卡容量，需要并行策略。

### Question 6: ZeRO Stage Comparison / ZeRO阶段比较
**Problem（问题）**: Given a model requiring 80GB per GPU with standard DP across 8 GPUs, how much memory per GPU at each ZeRO stage? / 给定标准DP跨8卡每卡80GB，各ZeRO阶段每卡多少？

**Solution（解答）**:
- Stage 1 ($P_{os}$): 80/4 = 20 GB (4× reduction)
- Stage 2 ($P_{os+g}$): 80/8 = 10 GB (8× reduction)
- Stage 3 ($P_{os+g+p}$): 80/8 = 10 GB for $N_d$=8 (linearly scales with GPU count; 64 GPUs → 64× reduction)
- 注意：Stage 3与GPU数成线性关系。

### Question 7: LoRA vs Full Fine-Tuning / LoRA vs 全量微调
**Problem（问题）**: A Transformer layer has hidden dimension d=4096. Compare trainable parameters for: (a) Full fine-tuning of $W_q$, (b) LoRA with rank r=8. / 隐藏维度d=4096，比较全量微调和LoRA(r=8)的参数量。

**Solution（解答）**:
- (a) Full FT: $W_q$ is $d \times d = 4096 \times 4096 = 16.8M$ parameters
- (b) LoRA: A ($r \times d$) = 32,768; B ($d \times r$) = 32,768; Total = 65,536 ≈ 0.066M
- Ratio: ~256× fewer parameters with LoRA
- LoRA参数量仅为全量微调的约1/256

### Question 8: RLHF Pipeline / RLHF流程
**Problem（问题）**: Describe the three steps of RLHF and explain why each step is necessary. / 描述RLHF的三个步骤并解释每步的必要性。

**Solution（解答）**:
- **Step 1 — SFT**: Supervised finetuning on high-quality demonstrations gives the model a baseline ability to follow instructions and generate appropriate responses. / 监督微调使模型获得遵循指令和生成适当回复的基础能力。
- **Step 2 — Reward Model**: Train a model to predict human preferences from pairwise comparisons. Necessary because we need a differentiable signal for RL optimization. Human labeling for every generation is too expensive. / 训练奖励模型预测人类偏好。为RL优化提供可微信号，人工标注每条生成太昂贵。
- **Step 3 — PPO**: Optimize the LLM policy using the reward model as reward signal, with KL penalty to prevent the model from deviating too far from the SFT model (avoiding reward hacking). / 用奖励模型优化策略，KL惩罚防止偏离SFT模型（避免奖励黑客）。

### Question 9: ReAct Agent / ReAct智能体
**Problem（问题）**: Explain how the ReAct framework works and why it improves over pure reasoning or pure action approaches. / 解释ReAct框架的工作原理及其相比纯推理或纯行动方法的改进。

**Solution（解答）**:
- ReAct interleaves **Thought** (reasoning) and **Action** (tool use) steps:
  1. **Thought**: LLM reasons about the current state and decides what to do. / LLM推理当前状态并决定做什么。
  2. **Action**: LLM calls a tool/API and observes the result. / LLM调用工具/API并观察结果。
  3. **Observation**: The result is fed back for the next thought. / 结果反馈给下一步思考。
- Improvement over pure reasoning: grounds reasoning in real evidence from tools, reducing hallucination. / 比纯推理好：将推理基于工具提供的真实证据，减少幻觉。
- Improvement over pure action: reasoning helps plan which actions to take and interpret results. / 比纯行动好：推理帮助规划行动和解释结果。

### Question 10: Smoothing Methods Comparison / 平滑方法比较
**Problem（问题）**: Compare Laplace smoothing, interpolation, and Kneser-Ney smoothing. / 比较拉普拉斯平滑、插值平滑和Kneser-Ney平滑。

**Solution（解答）**:
- **Laplace (Add-1)**: simplest, adds 1 to all counts; often over-smooths, gives too much probability mass to unseen events. / 最简单，对所有计数加1；常常过度平滑。
- **Interpolation**: combines different n-gram orders with learned weights; more robust, can balance between long and short context. / 用学习到的权重混合不同n-gram阶；更鲁棒。
- **Kneser-Ney**: best performance; uses absolute discounting and continuation probability; considers how many different contexts a word appears in, not just raw count. / 性能最好；使用绝对折扣和延续概率；考虑词出现在多少不同上下文中。

### Question 11: Pipeline Parallelism Bubble / 流水线并行气泡
**Problem（问题）**: Explain why naïve model parallelism creates "bubbles" and how GPipe addresses this. / 解释朴素模型并行的气泡问题及GPipe的解决方案。

**Solution（解答）**:
- In naïve MP, layers are distributed across GPUs sequentially. GPU0 processes forward pass first, then GPU1, etc. During GPU1's forward pass, GPU0 is idle → "bubbles". / 朴素MP中层按顺序分配，GPU间存在顺序依赖，产生空闲（气泡）。
- GPipe splits a batch into micro-batches and pipelines them. While GPU1 processes micro-batch 1, GPU0 processes micro-batch 2. This fills idle gaps and reduces bubbles. / GPipe拆分微批次并流水线化，填补空闲间隙。

### Question 12: RAG Retrieval Timing / RAG检索时机
**Problem（问题）**: Compare different "when to retrieve" strategies in RAG. / 比较RAG系统中不同的检索时机策略。

**Solution（解答）**:
- **One-time**: retrieve before generation. Simple but may miss info for complex queries. / 生成前检索一次，简单但可能遗漏。
- **Token-based (Toolformer)**: special tokens trigger retrieval at specific positions. / 特殊Token在特定位置触发检索。
- **Uncertainty-based (FLARE)**: retrieve when model confidence is low. / 置信度低时检索。
- **Iterative/Adaptive**: multiple rounds interleaved with generation. / 检索与生成交替多轮。
